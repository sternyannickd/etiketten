# Installer

Diese Dateien baut GitHub automatisch nach jedem Push. Bitte nicht von Hand ändern.

- **Windows:** `Etikettendruck-Installer-Windows.exe` doppelklicken.
- **Linux:** `Etikettendruck-Installer-Linux.sh` doppelklicken → „Ausführen“.

Erneut ausführen = Update. Eigene Produkte und Einstellungen bleiben erhalten.

Ausführlich: [docs/INSTALLATION.md](../docs/INSTALLATION.md).
`STAND.txt` zeigt, aus welchem Commit die Installer stammen.
